# JobMate AI — Job Intelligence (free mode)

Job Intelligence uses zero-cost Google Search links. It does not require a Brave subscription, paid search API key, additional D1 migration, or extra Worker secret.

## How it works

1. Enter a role and location, or leave the role blank to use general entry-level terms relevant to warehouse, production operator, helper, and QC work.
2. JobMate creates links for Google Jobs, Indeed Indonesia, JobStreet Indonesia, LinkedIn Jobs, company career-page searches, and operational roles across industries.
3. The destination search engine supplies the live results. Open the employer's original vacancy page and verify the posting date, requirements, location, and application channel.
4. Use **Siapkan CV untuk Posisi Ini** to hand the role context to the existing ATS checker.

## Privacy and accuracy

- Candidate name, phone, email, CV text, and profile details are not sent to Google or other search engines. Only the role keywords and location are included in search URLs.
- JobMate creates search links; it does not scrape search-result pages or claim that a vacancy is currently open.
- A search result is a lead, not a verified vacancy. Confirm the role on the employer's official career page before applying.
- Be careful with requests for application fees, deposits, OTPs, passwords, or payment for recruitment.

## Cost

- No paid search API is used in this mode.
- No Brave API key or additional D1 migration is required.
- Normal hosting, existing AI-provider usage, and internet/data charges remain separate.
